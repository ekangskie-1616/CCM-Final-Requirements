When we started Mission 1, we honestly didn’t know much about cloud computing. By Mission 10, we were able to build a working web app together. We set up an Ubuntu VM in VirtualBox, installed Docker, and ran WordPress and MySQL as two containers using Docker Compose. We tested our project by creating a post and rebooting the VM. The post was still there, showing us how Docker volumes help preserve data.

Throughout the missions, we encountered several challenges. Our SSH connection was initially refused because OpenSSH was not installed. We also experienced YAML errors in our Docker Compose file because of incorrect spacing. After several attempts, we learned to check our configuration using docker compose config before running the containers. We also learned to allow SSH through port 22 before enabling the firewall to avoid losing access to the VM.

We configured a UFW firewall to allow SSH and HTTP traffic, and we created a backup script that runs daily using cron. We also discovered that our VM uses UTC time, which caused the backup schedule to run at a different time than expected. These missions helped us improve our teamwork and technical skills. In the future, we want to learn how to secure our website using HTTPS, protect passwords more effectively, and deploy our project on a real cloud platform such as AWS.
